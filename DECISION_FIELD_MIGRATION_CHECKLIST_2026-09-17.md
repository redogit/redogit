## Parameterization requirement for future updates

Every new Decision Field specialization should declare:

```text
X = possibilities / conditions
O = observer / task / obligation / goal context
D = consequential distinctions
R = typed relations
F = admitted functions/operators
E = evidence/provenance/uncertainty/claim ceiling
G = desired bounded result
U = unresolved remainder
```

Every operator should declare:

```text
preconditions
preserved invariants
allowed mutation
cost/resource bound
certificate/evidence
failure mode
reconstruction/lift map if destructive
```
