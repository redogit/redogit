# Dean's fixed list — a second local rounding counterprobe

**Status:** approved Step 16 after [Step 15](PNP_DEAN_ONE_DEGREE_RANK_REPAIR_2026-09-29.md). This record tests one fixed nine-vertex carrier, \(H=\overline{C_9}\), against the preceding complete clique, odd-cycle, and seven-vertex rank rows. It admits only that pattern and its exact input-edge check. It does not open a general odd-antihole catalog or a universal Dean solver.

## 1. The next pair the old linear view cannot distinguish

The Dean supplies a fixed simple incompatibility graph \(G=(V,E)\), target \(k\), and omission budget \(b=|V|-k\). Let \(x_v\in\{0,1\}\) mean select vertex \(v\), and \(y_v=1-x_v\) mean omit it. Make four copies \(H_0,\ldots,H_3\) of \(\overline{C_9}\), with labels \(0,\ldots,8\) modulo nine. Inside each block, every nonconsecutive pair is an edge; add only three bridges \((H_i,0)(H_{i+1},0)\) for \(i=0,1,2\). The connected graph has \(n=36\), \(m=4(36-9)+3=111\). Each block permits at most two selected vertices: independent vertices in \(H\) are pairwise adjacent in \(C_9\), whose largest clique has size two. Labels 2 and 3 in every block avoid all bridges and attain \(\alpha(G)=8\), hence \(\tau(G)=28\). At the declared \(k=9,b=27\), the answer is **NO**.

The preceding linear view remains inconclusive even if **all** of its clique and odd-cycle rows and **all** admitted Step 15 seven-vertex rows are supplied. Put \(x_v=1/4\), or \(y_v=3/4\), everywhere. A clique inside \(H\) has at most four vertices, and a clique crossing a bridge has at most two, so every clique row holds. Any simple cycle stays in one block because the interblock edges are bridges. An odd cycle of length \(\ell\ge3\) has \(\ell/4\le(\ell-1)/2\), so every odd-cycle row holds. Every valid seven-vertex Step 15 row also holds, whether or not such a pattern is present, since its left side is \(7/4<2\). Yet \(x(V)=9=k\) and \(y(V)=27=b\). Thus no nonnegative weighted certificate from the preceding row family can cross this budget.

This is an exact LP boundary. Each block has nine four-cliques \(Q_i=\{i,i+2,i+4,i+6\}\) modulo nine, and every vertex belongs to four of them. Weight each of the 36 four-clique omission rows by \(1/4\). Their loads are all one, so the Step 14 overlap penalty is zero and the bound is \(36(3/4)=27\), attained by the displayed fractional point. In this symmetric bridge construction, three blocks do not hide a unit at the analogous first impossible target: the same four-clique weighting gives \(81/4=20.25>20=b\). Four is the first block count at which this particular fractional construction reaches the budget. This is not a minimality claim over all graphs.

## 2. One fixed nine-vertex rounding and its cost

For an ordered candidate \(\phi(0),\ldots,\phi(8)\), verify nine **distinct** input vertex IDs and all 27 unordered nonconsecutive pairs as edges in the **supplied** \(E\). The nine \(Q_i\) are then cliques. Summing their existing inequalities gives \(4x(H)\le9\). Because an actual selection has integral \(x(H)\), one local rounding yields

\[
x(H)\le\lfloor9/4\rfloor=2,
\qquad y(H)\ge7.
\]

Equivalently, the nine four-clique omission requirements sum to \(4y(H)\ge27\), then \(y(H)\ge\lceil27/4\rceil=7\). Each of the 27 required edges occurs in at least one listed four-clique; some occur more than once. Consecutive pairs need not be checked as nonedges: extra input edges preserve the bound. The old fractional point has \(x(H)=9/4\), so it fails precisely this locally rounded row. Round within each of the four verified blocks **before** aggregation to obtain \(4\cdot7=28>b=27\). Aggregating unrounded rows first gives only \(4y(V)\ge108\), hence \(y(V)\ge27\), and loses the unit.

A supplied occurrence needs 27 fixed-edge lookups after identity checks. Reuse the exact rational weighted overlap certificate from Steps 14–15: for admitted local rows \(S_i\) with required omissions \(d_i\) and nonnegative rational \(\lambda_i\), set \(L_v=\sum_{i:v\in S_i}\lambda_i\) and \(B=\sum_i\lambda_i d_i-\sum_v\max(0,L_v-1)\). Every integral omission set has size at least \(B\); here a verified nine-vertex row has \(d_i=7\). The four disjoint rows with unit weights give \(B=28>27\), a sound **NO** receipt. A separately checked independent nine-set gives **YES**; otherwise the procedure returns **UNKNOWN**. Receipt verification is polynomial in the input, receipt size, and rational bit lengths. Enumerating all nine-subsets and finitely many labelings has a formal \(O(n^9)\) bound for this **fixed** motif, but is not advertised as practical at 400 vertices. A capped search returns UNKNOWN on exhaustion.

## 3. Attack the admission and overlap seams

Delete just the required edge \((H_0,0)(H_0,2)\) from the four-block graph. It now has \(m=110\). The first block can select labels 0, 1, 2; the other blocks can each select 3, 4. These nine vertices form an independent set: all internal selected pairs are consecutive labels or the deleted edge, and no selected bridge has both endpoints. Each unchanged block allows at most two selections, while the changed block allows at most three, so \(\alpha=9,\tau=27\). At the **same** \(k=9,b=27\), the answer is **YES**. A loose nine-vertex resemblance rule would assign the invalid first block \(d=7\) and falsely give \(B=28>b\); the 27-edge check rejects that occurrence. This is the required counterexample to unsafe admission, not evidence for another carrier.

Glue two genuine \(H\) copies at label 0 and put no other edges between their distinct vertices. The graph has 17 vertices and \(\alpha=4\), witnessed by labels 2 and 3 from each copy, hence \(\tau=13\). At \(k=4,b=13\), naive addition of their omission counts would give \(7+7=14\) and a false NO. Their one shared vertex has load two, so the old overlap penalty subtracts one: \(B=7+7-1=13\), correctly inconclusive on this YES graph. No overlap machinery is added.

## 4. Provenance, world relation, and stop rule

The carrier proof is elementary counting with a single integer rounding. A disposable Python 3.12.14 fixture probe checked the 27-edge pattern, all nine four-cliques and their vertex incidences, the three- and four-block bridge optima by two-state dynamic programming, the one-edge YES witness, and the shared-vertex YES graph by enumeration. `python3 step16_nine_vertex_counterprobe.py` printed `PASS exact Step 16 finite counterprobe`; script SHA-256 `31a50cb52f3c1ac352b8382b59d1e90d4e2f0aa35e41fa103ca5288f74cf6ec9`. The finite check supports these instances; the displayed counting proof establishes the row for any admitted occurrence.

The odd-antihole rank inequality is established mathematics, discussed by Euler, Jünger and Reinelt in [*Generalizations of Cliques, Odd Cycles and Anticycles and Their Relation to Independence System Polyhedra*](https://pubsonline.informs.org/doi/10.1287/moor.12.3.451) (1987, attributing the graph result to Padberg). The unrestricted rank-separation problem is a different task; see Coniglio and Gualandi, [*On the exact separation of rank inequalities for the maximum stable set problem*](https://optimization-online.org/2014/08/4514/) (2014). No facet claim is made for a nine-vertex occurrence embedded in an arbitrary larger graph.

For a fixed symmetric pairwise conflict schedule, a verified nine-job exclusion pattern permits at most two simultaneous jobs. This can reject an impossible requested batch under those exact edges; changing schedules, weights, or non-pairwise interactions need a fresh model. It is an application of a graph certificate, not evidence about a deployed scheduler.
