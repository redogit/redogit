# About me

## Hi, I'm redogit.

Welcome to my corner of GitHub. My public repositories explore C#, .NET MAUI games, neural networks, and open research tooling. This is a place to follow the code, try an idea, and see where it leads.

### Code and experiments

- **[Conscience64](https://github.com/redogit/conscience64)** — A privacy-safe research space with deterministic carrier identities, provenance-aware recovery, I / R / P / O navigation, and preserved Cross-Carrier / Float64 research checkpoints.
- **[MauiBrickBreak](https://github.com/redogit/MauiBrickBreak)** — A brick-breaker game built with .NET MAUI and C#.
- **[FirstNeuralNetwork](https://github.com/redogit/FirstNeuralNetwork)** — The original C# neural-network experiment plus preserved REDO and Adaptive Connectivity Diagnostic Network successor work.
- **[Orbit Engine](https://github.com/redogit/orbit)** — My fork of [bijington/orbit](https://github.com/bijington/orbit), a game engine and sample games built on .NET MAUI Graphics. This is distinct from the separate Orbit Lab research lineage.
