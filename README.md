# redogit

## Do it. Inspect it. Redo it better.

`redogit` is my public working rule: preserve what actually happened, keep the useful part, rebuild the smallest thing that matters, verify the successor, and keep going.

Git history stays history. A redo is a successor, not a rewritten past.

See **[REDOGIT.md](REDOGIT.md)** for the rule.

## Current public projects

- **[Conscience64](https://github.com/redogit/conscience64)** — A privacy-safe research space with deterministic carrier identities, provenance-aware recovery, I / R / P / O navigation, and preserved Cross-Carrier / Float64 research checkpoints. Its REDO path now favors compact source, manifests, regeneration, and executable integrity checks over incomplete archive transport.
- **[MauiBrickBreak](https://github.com/redogit/MauiBrickBreak)** — The original .NET MAUI/Orbit game remains as history. The current successor extracts ball, paddle, block, and collision behavior into a framework-independent .NET 10 core with executable checks.
- **[FirstNeuralNetwork](https://github.com/redogit/FirstNeuralNetwork)** — The original C# experiment remains as history. The current successor is a deterministic .NET 10 logistic-neuron implementation with an executable OR-classification check; earlier Adaptive Connectivity successor work remains preserved too.
- **[Orbit Engine](https://github.com/redogit/orbit)** — My upstream-derived fork of [bijington/orbit](https://github.com/bijington/orbit). REDOGIT keeps upstream attribution explicit and keeps this fork separate from the unrelated Orbit Lab research lineage.
